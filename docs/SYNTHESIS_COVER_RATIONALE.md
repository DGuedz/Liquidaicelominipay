## Goal
Communicate the full LiquidAI thesis in one frame for judges scanning many submissions quickly.

## Composition Logic
1. Left side (problem + promise):
- Hero title: `LiquidAI`
- Positioning: `Agentic Treasury OS`
- Core value: `Invisible DeFi for the real world`

2. Middle-left (product mechanics):
- Three bullets map directly to architecture:
  - idle cUSD -> autonomous yield
  - Self Protocol identity gate

3. Right side (proof panel):
- Mobile-like dashboard card reinforces MiniPay/mobile-first execution.
- Quantitative snapshot (`$1,257.60`, `4.8%`) signals measurable economic impact.

4. Bottom-right (track fit):
- Explicit stack chips: `CELO`, `SELF`, `ZYFAI`
- Makes track alignment immediately legible for judges.

## Branding Decisions
- Dark-premium palette to signal institutional trust and security.
- Core colors from project identity:
  - emerald/lime accents (`#35D07F`, `#A3D977`)
  - cyan support (`#06B6D4`) for technical depth
- Rounded cards and high-contrast typography preserve mobile readability.

## Why it helps scoring
- Fast comprehension in <5 seconds.
- Clear link between user pain, agent behavior, and on-chain stack.
- Strong fit with Celo + Self + Zyfai tracks without changing product narrative.
